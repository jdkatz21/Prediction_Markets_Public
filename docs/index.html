Kalshi-Implied Macroeconomic Expectations

Data supporting "Kalshi and The Rise of Macro Markets" (Diercks, Katz, Wright 2026)

Daily probability distributions and statistical moments on macroeconomic expectations of Fed Funds Rates and other macroeconomic variables derived from Kalshi prediction market data.

Please cite:
Diercks, A., Katz, J., & Wright, J. (2026). Kalshi and The Rise of Macro Markets. NBER Working Paper No. 34702

About This Data

This dataset contains processed data from Kalshi prediction markets, providing daily estimates of market-implied probability distributions for key macroeconomic variables including Federal Funds Rates, CPI (both headline and core), GDP growth, and unemployment rates.

The data is derived from trade-level and orderbook-level observations from Kalshi's prediction markets and is updated daily through an automated pipeline. Researchers can use this data to study how market expectations evolve over time and how they respond to economic news and policy announcements.

Data Format: All files are provided as CSV (comma-separated values) files with headers. The distribution files use wide format where each row represents a date and contract, with one column per strike value containing the probability mass at that outcome. The moments files contain summary statistics with one row per date.

Update Frequency: This dataset is updated weekly on Fridays, approximately noon EST.

Available Datasets

Probability Distributions
Daily probability distributions for each macroeconomic variable. Each row represents a date and contract, with one column per strike value containing the probability at that outcome, plus a total_volume column. Only includes contracts within 2 months of the horizon and excludes the most recent day.

Statistical Moments
Daily summary statistics (mean, variance, skewness, kurtosis, etc.) computed from the probability distributions. Each row represents one date with multiple statistical measures.

Raw Trades
Every trade on each Kalshi market, as returned by Kalshi's API. Each row is one trade, with its market ticker, time, price and size. These are the inputs to the distributions and moments above.
